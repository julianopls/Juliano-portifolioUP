# Portfólio do Juliano Rafael

Portfólio pessoal responsivo em HTML, CSS e JavaScript.

## Incluído
- Foto pessoal
- Currículo em PDF para download
- E-mail
- WhatsApp com mensagem pré-preenchida
- Instagram
- LinkedIn
- GitHub
- Projetos com links diretos para os respectivos repositórios
- Menu responsivo
- Carrossel de projetos
- Animações
- Formulário de contato

## Mensagem do WhatsApp
Ao clicar em "Mandar mensagem no WhatsApp", a conversa abre para o número informado com:
"Gostei muito do seu portifolio!!"

## Como abrir
Abra o `index.html` no navegador ou use o Live Server no VS Code.
